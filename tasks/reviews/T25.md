- **Spec conformance** — `0008_tasks` additive migration matches spec 02 (CHECKs on title / `completed_at`↔`done` / `application_id⇒job_id`, composite + FK indexes, soft delete, no cascade). API contract, pagination, `due_before` filtering, overview shape all match the spec 03 additions. Beat config matches spec 06: `generate_followup_tasks` hourly on default queue, `remind_due_tasks` at `crontab(hour=8)` on the email queue with `timezone="Asia/Ho_Chi_Minh"`.
- **Day boundaries** — `day_bounds` computes VN midnight; `due_tasks`/overview use `due_at < end` (today + overdue, excludes tomorrow), consistent between the reminder mail and the overview card. Frontend `taskGroup` groups by VN day; no-deadline → "Sắp tới".
- **Privacy** — Reminder body contains only escaped task titles + deadlines; no CV/candidate contact data fetched. Celery payloads carry IDs/checkpoints only. No logging of PII (diff has no log/print statements). `task_done` activity payload is `{task_id}` only.
- **Human-in-the-loop** — Reminders are internal mail to the task owner's own address; they never change a stage, reject a candidate, or send candidate-facing interview/rejection/offer mail. `is_reminder` requires an exact deterministic id + Message-ID + null application/template before the worker treats a row as a reminder, and the worker re-checks `to_email == actor.email` and rebuilds the list before SMTP; the public email API still requires an Application and cannot mint this marker.
- **Permissions** — Recruiter restricted to own tasks (`mine=false`→403, cross-assign→403, job-scope loss→403/404); verified by `test_assignee_scope_links_and_membership_revocation`. Overview interview/job lists and `application-options` enforce job scope. Completion failure rolls back atomically (`test_completion_rolls_back_when_activity_fails`).
- **UI** — All new strings in `i18n/vi.ts`; no technical terms surfaced to HR; error codes mapped to Vietnamese messages; selectors use `htmlFor`/`id`; loading/empty/error/retry states present; save path guards double-submit and post-unmount cache writes. Drawer create fixes the Application link.
